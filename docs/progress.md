## 尚未完成或尚未验收

- 真实 HMCL／PCL／Prism 和 Minecraft 图形客户端联机，及真实第三方提供方／SMTP；模拟上游与 HTTP 集成不能替代这些验收。
- 旧 Janus 正在进行的交互及旧 refresh token 不承诺无缝延续；无法可靠恢复授权绑定的令牌需重新授权，已有账户、客户端及密钥不因此重建。
- Join 缓存仍为单进程内存，多实例需要共享存储；聊天玩家证书未实现，功能标记明确关闭。
- 任意 PHP 插件不能直接运行；并非已宣称 Blessing Skin 全部插件和每个可选 OIDC 扩展兼容。描述 Markdown／长度设置、部分管理细节及中文硬编码仍待逐项核对。
