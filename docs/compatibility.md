# 功能与兼容范围

Natayark Skin Server 是独立实现。兼容工作的目标是让已有账户、角色、材质和启动器接入继续可用；不依赖 PHP 或 Janus 运行。

## 已有能力

上传奖励去重与次数上限、认证和上传资源预算、动态缓存、私有及删除语义、自动文件回收和夏令时处理见[资源与安全说明](security-hardening.md)。这些规则包含有意收紧的业务行为，应在旧站升级前阅读。

账户和第三方绑定、邮箱验证、密码重置、应用授权、皮肤与披风、衣柜、角色、积分、签到、举报、通知及管理后台已实现。静态材质预览与 3D 预览分别处理皮肤模型、外层和披风。

用户、角色和举报管理支持字段条件、列表、括号、`and/or/not`、日期及排序。例如：

```text
score>=100 verified sort:-score
uid:123 not skin:0
status:0 report_at>=2026-01-01
```

网站验证码支持本站图片、reCAPTCHA v2 复选框和 invisible。join 状态由数据库共享，支持跨进程验证；所有实例必须使用相同数据库和 `APP_KEY`。

## 验证方式

自动化测试覆盖账户、积分、材质、原生集成、Yggdrasil、Connect、管理和外观。高级搜索使用独立生成的参考查询检查结果；跨进程测试实际启动独立 HTTP 服务，检查 join、过期和吊销。

已有 MySQL 5.7.26 数据库的完整隔离副本通过结构与业务核对。原始表的字段、索引、外键和内容保留；扩展状态使用独立表。描述列扩大为 TEXT 是可选迁移。

更细的协议说明见 [protocol-compatibility.md](protocol-compatibility.md)，第三方账户衔接见 [authentication.md](authentication.md)。

## 尚需实测或未实现

- 真实 HMCL、PCL、Prism 与不同 Minecraft 图形客户端的完整联机流程。
- 真实第三方授权回调、SMTP 投递和 CDN 刷新；本地模拟不能代替这些验收。
- 旧浏览器会话及部分旧授权交互需要重新登录或授权。
- 玩家聊天证书尚未提供，对应功能标记关闭。
- 插件市场暂不实现；PHP 插件和 PHP 队列任务不会在 Node.js 中执行。
- 日期搜索支持常用绝对与相对格式，不保证覆盖 PHP 自然语言日期解析器的全部输入；多语言文案仍在补充。
